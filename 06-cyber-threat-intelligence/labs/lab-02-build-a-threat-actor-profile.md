# Lab 02 — Build a Threat Actor Profile

**Type:** Lab Guide (uses public reporting only)

## Objective
Build a short threat-actor profile using the Diamond Model, based entirely on public reporting.

## Prerequisites
- Completed Lab 01.
- Access to public CTI reporting (vendor blogs, MITRE ATT&CK groups pages, government advisories).

## Steps
1. Pick one publicly tracked threat actor/group from [MITRE ATT&CK Groups](https://attack.mitre.org/groups/).
2. For each Diamond Model element, note what's publicly known: Adversary (attribution/aliases), Capability (tools/malware used), Infrastructure (typical C2 patterns, hosting), Victim (targeted sectors/regions).
3. Map 3-5 of the group's known techniques to ATT&CK technique IDs.
4. Write a one-page profile summarizing the above, citing every source.

## Expected outcome
A one-page, fully-cited threat-actor profile using the Diamond Model and ATT&CK mapping.
