# 101 Cybersecurity Analyst

A personal study roadmap for the [Complete Hands-On Cybersecurity Analyst Course](https://www.udemy.com/course/the-complete-hands-on-cybersecurity-analyst-course/).

## Current repository state

This repository currently contains this study outline only. It does **not** yet contain completed course modules, lab evidence, tools, or writeups. Module material will be added only when there is an original, reviewable artifact to share.

## Planned study areas

- Networking and Linux fundamentals
- Virtual-lab setup
- Threat detection, hunting, and intelligence
- Email, malware, and incident-response analysis
- SIEM, monitoring, forensics, and vulnerability management
- Authorized web, wireless, and reverse-engineering labs

## Publishing standard

Future additions will include the lab objective, authorized scope, reproducible setup or safe sample data, observed result, and a short reflection. Credentials, personal data, target details, and copyrighted course material will not be committed.
