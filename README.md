## 📚 Course Overview

This course covers a wide range of cybersecurity skills — from foundational networking to advanced threat analysis, incident response, ethical hacking, and malware analysis. All labs are conducted in a self-built virtual environment to simulate real-world scenarios.

## 🧭 Course Modules

### 1. Networking Fundamentals
- Intro to Networking 101
- Understanding Computer Networks
- Local Area Networks (LAN)
- DHCP
- OSI & TCP/IP Models (Overview + Practical Layers 1–7)
- Intro to Packets and Frames
- Firewalls and Firewall Rules
- Intro to DNS

### 2. Linux Basics
- Linux command line fundamentals
- File system navigation and permissions
- Scripting essentials for security tasks

### 3. Virtual Lab Environments
- Setting up virtualization software (VMware / VirtualBox)
- Building a home lab for safe testing
- Configuring network segments within VMs

### 4. Threat Detection & Analysis
- Security event triage
- Using EDR tools
- Writing detection rules

### 5. Threat Hunting
- Proactive threat hunting methodologies
- Hunting with SIEM queries
- Identifying IOCs and TTPs

### 6. Cyber Threat Intelligence (CTI)
- CTI frameworks (MITRE ATT&CK, Diamond Model)
- Threat actor profiling
- Indicator enrichment

### 7. Malware Analysis
- Static and dynamic analysis techniques
- Sandboxing malware samples
- Analyzing PE files and scripts

### 8. Email & Phishing Analysis
- Phishing email anatomy
- Header analysis
- URL and attachment detonation

### 9. SIEM Tools
- Splunk (searching, dashboards, alerts)
- Elastic Stack
- Wazuh

### 10. Incident Response
- IR lifecycle: Detect → Contain → Investigate → Mitigate → Recover
- Creating incident reports
- Evidence preservation

### 11. Network Monitoring & Forensics
- Packet capture and analysis (Wireshark, tcpdump)
- Network flow analysis
- Identifying anomalous traffic

### 12. Vulnerability Scanning & Management
- Using Nessus / OpenVAS
- CVE assessment and prioritization
- Patch management workflows

### 13. Password Cracking
- Hashcat and John the Ripper
- Wordlists and rules
- Defending against credential attacks

### 14. WiFi Pentesting
- WPA2 handshake capture
- Aircrack-ng suite
- Rogue AP setup

### 15. Web Application Pentesting
- OWASP Top 10
- Burp Suite basics
- SQL injection, XSS, and more

### 16. Reverse Engineering
- Assembly basics
- Static analysis with Ghidra / IDA
- Dynamic analysis with x64dbg

### 17. Writing Malware Emulations
- Building benign malware-like scripts for detection testing
- Purple team use cases

### 18. C2 Frameworks
- Intro to Command & Control infrastructure
- Cobalt Strike / Sliver overview
- Detection and defense strategies

### 19. Purple Teaming
- Red vs. Blue team collaboration
- Adversary emulation plans
- Improving detection coverage

### 20. Honeypots
- Deploying honeypots (Cowrie, HoneyD)
- Analyzing attacker behavior
- Integrating with SIEM
