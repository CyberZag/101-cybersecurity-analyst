Interactive OSI stack

DHCP

DORA: Discover → Offer → Request → Acknowledge. Lease data helps link IP, hostname, MAC, and time during triage.

DNS

Pivot from domain to resolver response and IP. Hunt for suspicious domains, long subdomains, high NXDOMAIN counts, and beaconing patterns.

Firewalls

Use least-privilege rules and segmentation to restrict flows. Treat allows, denies, and policy changes as security telemetry.

Investigation example

  1. Attribute the source IP with DHCP records.
  2. Identify the domain and answer using DNS logs.
  3. Review firewall/proxy flow details for destination, port, and timing.
  4. Inspect a PCAP for TLS metadata, TCP flags, and related connections.
  5. Assess whether the traffic fits normal egress policy.
